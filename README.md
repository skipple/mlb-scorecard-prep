# MLB Scorecard Prep

**Live site: [skipple.github.io/mlb-scorecard-prep](https://skipple.github.io/mlb-scorecard-prep/#)**

A simple, text-first web page for getting ready to keep score at an MLB game. Pick a game from the day's schedule and it pulls together everything you need to fill out a scorecard, on screen or printed to bring to the ballpark.

For each game it shows:

- Starting lineups and pitchers, plus bench and bullpen, with season stats and jersey numbers
- Team offense/defense stats and standings
- Umpires, stadium, weather, wind and start time
- In-game details (actual start, attendance, end time, duration) as they become available

Data comes from the [MLB Stats API](https://statsapi.mlb.com).
